openRaGWorM is a basic Recurrent Generative World Model written in C. It is lightweight enough to run on a ten-year-old CPU.

Written originally for Debian Linux.

Input images should be 96x54px, while input controls should be sets of 4 32-bit floats.

Copy your images into the ./dataset folder and set Model->Current_State = CURRENT_STATE_TRAIN_AUTOENCODER to begin.
